# LynxBox 硬件工业设计规格

**项目**: LynxBox - AI语音交互盒子 | **版本**: v1.0 | **日期**: 2025-10-09
**状态**: 设计规划 | **关联文档**: [spec.md](spec.md), [plan.md](plan.md)

---

## 📐 设计概述

### 产品定位
LynxBox是一款嵌入式AI语音交互模块,设计用于**永久植入毛绒玩具内部**,赋予普通玩具对话交互能力。设计需兼顾**紧凑体积**、**易于集成**、**长期可靠性**和**成本控制**。

### 核心设计原则
1. **永久嵌入式设计** - 整机密封,无需用户拆卸维护
2. **紧凑高效** - 最小化体积,适配多种玩具尺寸
3. **易于集成** - 标准化接口,便于玩具厂商生产线集成
4. **防护可靠** - 防尘防水,抗跌落设计
5. **充电便利** - 外露USB-C接口,可穿透玩具外层充电

## 🎯 机芯盒整体尺寸与形态

### 主体尺寸要求

| 参数 | 目标值 | 上限值 | 说明 |
|------|--------|--------|------|
| 长度 (L) | 70mm | 80mm | 适配中小型毛绒玩具 |
| 宽度 (W) | 50mm | 60mm | 宽度控制以适应玩具身体厚度 |
| 高度 (H) | 25mm | 30mm | 扁平设计,降低突出感 |
| 总体积 | ≤87.5 cm³ | ≤144 cm³ | 参考对象:小型充电宝 |
| 重量 | ≤80g | ≤100g | 包含电池,不影响玩具手感 |

### 外形设计方向

**推荐造型**: 圆角矩形盒体
- 所有边角倒圆角(R≥2mm),避免顶破毛绒面料
- 上下壳体对称设计,便于注塑成型
- 整体扁平化,减少玩具内部突起感

**替代方案**: 椭圆形卵石造型
- 更柔和的外观,适合柔软玩具
- 减少内部空间利用率

**材质建议**:
- 外壳: ABS工程塑料(高抗冲击)或PC/ABS合金
- 表面处理: 磨砂处理(增加与填充物摩擦力,防位移)
- 颜色: 中性色(黑色/深灰),或可定制玩具主题色

## 🔧 外观结构设计

### 1. 外壳分体设计

```
┌─────────────────────────────────┐
│     上壳 (Top Cover)            │  ← 包含: 按钮孔、麦克风开孔
├─────────────────────────────────┤
│                                 │
│      主板 + 电池腔体             │  ← 内部结构区
│                                 │
├─────────────────────────────────┤
│     下壳 (Bottom Cover)         │  ← 包含: USB-C口、扬声器网孔
└─────────────────────────────────┘
```

**上下壳连接方式**(推荐):
- **超声波焊接 + 结构胶密封**
  - 优点: 永久密封,防尘防水性能最佳,成本低
  - 缺点: 不可维修(符合一次性嵌入设计理念)
  - 适用场景: 量产型号,玩具出厂前集成

**替代方案**(用于开发/测试阶段):
- **卡扣式连接 + 4颗M2×6螺丝固定**
  - 优点: 可拆卸,便于调试和电池更换
  - 缺点: 密封性稍差,成本略高
  - 适用场景: 工程样机,小批量定制

**密封设计**:
- 外壳接缝处设计0.3mm凸台配合结构胶
- 超声波焊接能量导向筋(Tri角焊筋设计)

### 2. 按钮设计

**位置**: 上壳正面中央或侧面(需考虑玩具填充物压力)
**类型**: 金属圆顶按钮(Tactile Dome Switch)

| 参数 | 规格 | 说明 |
|------|------|------|
| 按钮直径 | Φ10-12mm | 平衡手感与防误触 |
| 行程 | 0.6-1.0mm | 清晰的按压反馈 |
| 按压力 | 300-400gf | 防止毛绒填充物误触发 |
| 防水等级 | IP54 | 防尘防溅水 |
| 寿命 | ≥100,000次 | 长期使用可靠性 |

**外观特征**:
- 按钮表面采用硅胶套,增加触感辨识度
- 按钮周围设计1-2mm凸台,隔离填充物压力
- 可选: 按钮下方集成LED指示灯(透光按钮设计)

**功能映射**:
- 短按1秒: 唤醒/待机
- 长按3秒: 开机(播放开机音乐)
- 长按5秒: 关机
- 长按10秒(关机状态): 重置

### 3. 麦克风开孔设计

**数量**: 2个麦克风(双麦阵列,用于降噪和打断检测)
**位置**: 上壳正面,左右对称分布

```
上壳俯视图:
┌───────────────────────┐
│  ●              ●     │  ← 麦克风1     麦克风2
│                       │     (间距30-40mm)
│        [按钮]         │
└───────────────────────┘
```

**开孔规格**:
- 直径: Φ1.0-1.5mm (对应INMP441等I2S麦克风)
- 数量: 每个麦克风1-3个小孔(组成阵列)
- 防护: 内侧贴防尘网(不锈钢丝网或PTFE透声膜)

**声学设计**:
- 开孔周围0.5mm凹槽,避免异物堵塞
- 内侧设计声学腔体,优化拾音指向性

### 4. 扬声器设计

**位置**: 下壳底部或侧面
**类型**: 动圈扬声器 + 功放芯片(MAX98357A等)

| 参数 | 规格 | 说明 |
|------|------|------|
| 扬声器尺寸 | Φ20-28mm | 平衡音质与体积 |
| 功率 | 2-3W | 足够室内使用音量 |
| 频响范围 | 300Hz-12kHz | 适合人声播放 |
| 阻抗 | 4Ω/8Ω | 常规规格 |

**音孔设计**:
- 网格孔阵列(每孔Φ0.8mm,间距1.5mm)
- 覆盖面积≥扬声器振膜面积的50%
- 内侧金属网罩(不锈钢/铜,防止异物进入)

**外观处理**:
- 音孔区域可采用同心圆/放射状图案设计
- 颜色对比(如金属色网罩+塑料外壳)

### 5. 充电接口

**类型**: USB Type-C接口(支持5V/1A-2A充电)
**位置**: 底壳侧面或底部,**配合延长线穿出玩具表面**

**接口规格**:
- 深度: 距外壳表面内凹1-2mm,便于插拔
- 开孔尺寸: 9mm × 3.5mm (留0.5mm余量)
- 防护等级: IP54(防尘塞保护)

**玩具集成方案**:
- **方案A**(推荐): 外置充电口 - 玩具背部或底部缝制隐藏式充电口,用魔术贴/拉链封闭
- **方案B**: 磁吸触点 - USB-C母座外接磁吸Pogo Pin,玩具外部磁吸充电
- **方案C**: 透传充电线 - 机芯盒预留USB-C延长线,穿出玩具表面(可热插拔)

**防护设计**:
- 硅胶防尘塞(可选,仅方案C需要)
- 接口周围导流槽,防止液体渗入

**外观标识**:
- 接口旁丝印充电图标(⚡),便于玩具厂商识别安装方向

### 6. 指示灯设计

**位置**: 按钮周围或正面顶部
**类型**: RGB LED(WS2812B或常规三色LED)

**功能定义**:
| 状态 | 颜色 | 模式 | 说明 |
|------|------|------|------|
| 开机 | 蓝色 | 呼吸(1s周期) | 系统就绪 |
| 配网中 | 蓝色 | 快闪(0.5s周期) | 等待配网 |
| 联网成功 | 绿色 | 常亮3秒 | 网络已连接 |
| 对话中 | 绿色 | 呼吸 | AI交互中 |
| 充电中 | 红色 | 常亮 | 正在充电 |
| 充电完成 | 绿色 | 常亮 | 电量100% |
| 低电量 | 红色 | 慢闪(2s周期) | <15%电量 |
| 错误 | 红色 | 快闪(0.3s周期) | 系统故障 |

**光学设计**:
- 导光柱设计,使光线柔和扩散
- 透光区域采用透明PC或半透明PMMA材料
- **玩具集成考虑**: 指示灯可透过薄层毛绒面料显示(建议玩具该位置使用浅色或透光性好的面料)

## 🔋 内部结构与布局

### 电路板 (PCB) 布局

**主板尺寸**: 60mm × 45mm (单层或双层板)
**关键芯片布局**:
```
┌────────────────────────────────┐
│ [USB-C] [充电IC] [温度传感器]  │
│                                │
│ [ESP32-S3-WROOM-1-N16R8]  [功放IC] │
│                                │
│ [IMU]  [电源管理IC]  [麦克风×2] │
│                                │
│ [天线区域-禁止铺铜]             │
└────────────────────────────────┘
```

**关键元器件（BOM要点）**:
- 主控模组: ESP32-S3-WROOM-1-N16R8（16MB Flash + 8MB PSRAM）
- 无线: 模组自带PCB天线，PCB边缘需预留天线净空区（参考模组资料）
- 其余器件按功能规格说明书 spec.md 执行

**固定方式**:
- 4个定位柱 + 螺丝固定(M2螺丝)
- 底部设计防震垫(EVA泡棉)

### 电池仓设计

**电池类型**: 锂聚合物电池(LiPo)
**推荐规格**:
- 容量: 1500-2000mAh (满足≥6小时续航,SC-006)
- 尺寸: 60mm × 35mm × 6mm (标准603562型号)
- 接口: PH2.0 2-pin连接器

**电池固定**(永久嵌入式):
- 专用电池舱,双面胶 + 结构胶永久固定
- 电池与PCB之间设计绝缘层(PI膜或Kapton胶带)
- **不可更换设计**: 电池寿命≥500次充放电循环(约2-3年使用寿命)

**安全保护**:
- 温度传感器(NTC)贴合电池表面
- 过充/过放/短路保护电路(TP4056等充电IC)
- 电池舱周围设计散热槽

### 散热设计

**热源**: ESP32-S3芯片、功放芯片
**散热方案**:
- 芯片下方PCB增加散热过孔(Via Stitching)
- 外壳内侧对应位置设计金属散热片接触位(可选)
- 外壳开槽设计(隐蔽式散热槽,不影响外观)

### 天线设计

**WiFi/蓝牙天线**:
- **方案A**: PCB板载天线(省成本,信号稍弱)
  - 需在PCB边缘预留20mm × 5mm禁铺铜区
  - 外壳该区域不得有金属件

- **方案B**(推荐): 陶瓷天线(信号强,抗干扰)
  - 型号推荐: Johanson 2450AT18A100
  - 通过IPEX连接器连接主板
  - 安装位置: 上壳内侧,远离金属件

**天线测试要求**:
- WiFi信号强度: ≥-70dBm @ 5米距离
- 蓝牙信号覆盖: ≥10米有效范围

## 🛡️ 安全与认证要求

### 产品安全标准

**符合标准**: GB 4943.1-2011《信息技术设备安全》

1. **机械物理性能**:
   - 无锐利尖端/边缘(边角倒圆R≥2mm),避免损坏玩具面料
   - 跌落测试: 1米高度跌落后无破损,功能正常
   - 振动测试: 模拟运输/使用场景,结构无松动

2. **电气安全**:
   - 充电电压≤5V,电流≤2A
   - 过充/过放/短路/过温保护电路
   - 电池保护板必须通过UL/IEC 62133认证

3. **环保要求**(RoHS):
   - 塑料外壳不含有害物质(铅、汞、镉、六价铬、PBB、PBDE)
   - 符合欧盟RoHS 2.0指令(如需出口)

### 电子产品认证

| 认证 | 说明 | 要求 |
|------|------|------|
| **SRRC** | 无线电型号核准 | WiFi/蓝牙设备必须(中国市场) |
| **质检报告** | 第三方检测 | 电商平台销售必需 |
| CCC认证 | 中国强制性产品认证 | 根据最终产品形态确定是否需要 |
| RoHS | 有害物质限制 | 出口欧盟需要 |
| FCC | 美国通信认证 | 出口美国需要 |
| CE | 欧盟合格认证 | 出口欧盟需要 |

### 防护等级

**建议防护等级**: IP54
- IP5X: 防尘(有限进入,不影响正常工作)
- IPX4: 防溅水(任意方向溅水无有害影响)

**实现措施**:
- 按钮、USB口采用密封结构
- 上下壳接缝处设计密封圈(硅胶条)
- 麦克风/扬声器孔防水膜处理

## 📦 装配与制造工艺

### 注塑成型工艺

**材料选择**:
- ABS塑料(阿科玛/奇美等品牌)
- 壁厚: 1.5-2.0mm(均匀壁厚,避免缩痕)
- 脱模斜度: ≥3°

**表面处理**:
- 磨砂纹理(VDI 3400标准,纹理深度24-30μm)
- 喷涂类肤质涂层(可选,提升手感)
- 丝印工艺(按钮图标、充电标识)

### 组装流程

```
1. 下壳安装:
   ├─ 安装主板(4颗螺丝固定)
   ├─ 连接扬声器排线
   ├─ 安装电池(连接PH2.0接头)
   └─ 贴绝缘胶带

2. 上壳安装:
   ├─ 安装按钮开关
   ├─ 粘贴麦克风防尘网
   └─ 安装指示灯导光柱

3. 合壳:
   ├─ 对齐上下壳
   ├─ 按压卡扣(如有)
   ├─ 拧紧4颗固定螺丝(M2×6)
   └─ 贴防拆标签

4. 功能测试:
   ├─ 开机测试
   ├─ 蓝牙/WiFi连接测试
   ├─ 语音对话测试
   └─ 充电测试

5. 包装入库
```
