## 三、快速判断技巧 ⚡

### **3秒判断法**（看主页首图）

**✅ 立即加入候选**：
- 主页9宫格视觉统一
- 色调温暖、治愈系
- 有毛绒玩具/柔软物品
- 有星座相关内容
- 粉丝数合适

**❌ 立即淘汰**：
- 图片杂乱、滤镜不统一
- 过度营销号（全是广告）
- 儿童母婴向（显得低幼）
- 冷淡风/性冷淡风（与毛绒违和）
- 男性粉丝过多

---

### **30秒深度判断法**（进入主页）

**看3个地方**：

1️⃣ **个人简介**
```
✓ 有标注星座 → 加10分
✓ 有"星座"相关词 → 加5分
✓ 有"独居"/"治愈"等词 → 加5分
✓ 有商务合作邮箱 → 专业，可联系
```

2️⃣ **最近10篇笔记**
```
✓ 至少5篇视觉质量优 → 合格
✓ 有毛绒/柔软物品 → 加分
✓ 有情感/治愈类内容 → 加分
✓ 商业笔记≤3篇 → 合格
```

3️⃣ **随机看一篇评论区**
```
✓ 评论真实（不是互关） → 合格
```

## 七、红旗信号（立即淘汰）🚩

**看到这些立即放弃**：

❌ **视觉红旗**
- 图片像"微商产品图"
- 过度美颜到失真
- 背景杂乱、光线差
- 滤镜不统一

❌ **内容红旗**
- 连续10篇都是广告
- 明显的拼团、低价团购
- 评论区都是"互关""回访"
- 粉丝明显买的（点赞比异常）

❌ **调性红旗**
- 母婴/儿童向（会让产品显得低幼）
- 低价好物为主（廉价感）
- 过度搞笑/夸张风格（与产品不符）
- 男性视角内容（目标客群不符）
